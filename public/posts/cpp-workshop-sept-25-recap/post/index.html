C++ Workshop Semester 2 2025 Recap

2025-09-07Swinux Committee 2 min read (217 words)
#event  #code 

That’s a wrap on the inaugural C++ Workshop for Swinux!⌗

President Dylan presenting the C++ Workshop

We hope all that attended in person or remotely had a great time learning about the fundamentals of C++. We have a list of resources hosted on our club GitHub repository should you wish to revisit the workshop, including slides, code and documentation regarding setup on Linux, Windows and Mac:

Find the Workshop materials here

We had a blast covering the following topics:

  • Basics of C++
  • Object-Oriented Programming
  • Memory Management
  • Data Structures
  • Template Meta-Programming

Alternatively, if you’re less interested in learning during the Workshop, the events held by the club provide an excellent opportunity to network with fellow students, learn new technologies and techniques.

Attendee showing the cmatrix effect in the terminal

We’d also like to say a small thank you to President Dylan for his work in hosting the Workshop and preparing all of the materials, and the rest of the committee for their support.

Lastly, if you’re looking out for more in-person events held by the club, keep a look out on our official channels for upcoming announcements. We look forward to seeing you again!
