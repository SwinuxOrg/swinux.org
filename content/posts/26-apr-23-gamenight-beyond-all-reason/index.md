Our next game night is set for Thursday the 30th of April @ 8PM!

Smashing the competition out of the water, Beyond All Reason was voted as the next game for the club games night. Beyond All Reason is a tactical Sci-Fi strategy game where you must destroy your opponent's commander to emerge victorious. Beyond All Reason features innovative and unique game mechanics including real-time projectiles and variable terrain to make engagements tactical and troop use thoughtful.


We encourage everyone interested to join in as we explore a deep and interesting take on the Real Time Strategy genre, all built on an open and freely available code base. You can download the game via the following link:

https://www.beyondallreason.info/
