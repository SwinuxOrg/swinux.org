We have just announced the **Introduction to Linux** Workshop!

* Time: October 9th @ 4:30 PM - 7:30 PM*
* Location: Hawthorn Campus, ATC101
* Host: @waruta
* Please complete pre-workshop before attending.

**Explore and learn the basics of using Linux Mint as a Desktop OS in this in-person workshop.**

We will cover the basic history of Linux and its competing OSes, what "Linux distros" are, its way of handling files and how software is installed and updated on it. This workshop will use Linux Mint and cover its bundled software and features.

There is a pre-workshop content for preparing for the workshop. This is mainly for setting up a virtual machine and installing Linux Mint onto it, which take a while. The pre-workshop can be done in your own time.

An online help desk session for the pre-workshop will be ran in the lobby voice channel in the Swinux Discord Server. It will take place on October 8th @ 4:30 PM, a day before the workshop. You may also ask for help with it on the Discord server outside of the help desk.

The workshop itself will start a few minutes after 4:30 PM. Please complete the pre-workshop content before attending.

There will be some homework activities that can be done after the workshop.

Attendance is likely in-person only. This workshop may be recorded, although we strongly recommend you attend. Materials used in this workshop will be provided online via <https://swinux.org> and the #events channel in the Discord server.
