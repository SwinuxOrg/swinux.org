If you've never used Linux before and have no clue how it works, you  may be wondering what all the fuss is about. To put it in very basic terms, Linux is another operating system, just like Windows or MacOS. It does most, if not all of the things you'd expect an operating system to do. So what is an operating system?

# What is an Operating System?
An operating system ties all of the physical hardware (your computer, laptop etc.) and software (your apps, files etc.) together to present it to you in an understandable and intuitive manner. It does a lot of work in the background in order to make using your device as easy and painfree as possible. However, an operating system is made up of a lot of smaller constituent systems which work together to give the appearance of a cohesive experience.

One major part of any operating system is how the physical hardware interacts with the software. You can have all of the storage, memory and processing power in the world, but if you can't effectively communicate with it and tell it what to do, then you don't have a functioning device. This is where something called the kernel comes in. 

# What is a Kernel?
A kernel provides the means to communicate between the hardware and software, making it easier for developers to create programs and apps. This is because they don't have to worry about how each specific piece of hardware is built or how to interact with them, just how they will interact with the kernel.
