*That's a wrap on the inaugural C++ Workshop for Swinux!*

We hope all that attended in person or remotely had a great time learning about the fundamentals of C++. We have a list of resources hosted on our club GitHub repository should you wish to revisit the workshop, including slides, code and documentation regarding setup on Linux, Windows and Mac:

[Find the Workshop materials here](https://github.com/SLHCC/cpp-workshop/tree/main)

We had a blast covering the following topics:

- Basics of C++
- Object-Oriented Programming
- Memory Management
- Data Structures
- Template Meta-Programming

Alternatively, if you're less interested in learning during the Workshop, the events held by the club provide an excellent opportunity to network with fellow students, learn new technologies and techniques.
